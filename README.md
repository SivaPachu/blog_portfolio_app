# MERN Stack Developer Portfolio & Blog

Hii Everyone! 👋

Welcome to my Developer Portfolio and Blog project! This is a sleek, modern, full-stack web application built with the MERN stack (MongoDB, Express.js, React, Node.js) and secured with Firebase Authentication. It is designed to showcase my web development services, live projects, and technical write-ups in a highly aesthetic, custom-themed environment.

---

## 📌 Project Overview

This project delivers a complete MERN-structured portfolio featuring a dedicated admin CMS (Content Management System) for publishing tech blogs. It boasts a premium deep charcoal UI with glowing cyan and blue glassmorphic accents built using Tailwind CSS. It demonstrates advanced full-stack development principles such as integrating Firebase for secure user authentication, executing robust CRUD operations via MongoDB Atlas, configuring secure environment variables, and achieving decoupled dual-platform deployment across Vercel and Render.

Developing this application helped me strengthen my understanding of full-stack API integration, resolving CORS policies between live cloud domains, managing secure database connections, and designing highly responsive, state-driven React interfaces.

---

## ✨ Features

- ✅ Full CRUD Blog CMS (Create, Read, Update, Delete) via Admin Panel 📝
- ✅ Secure User Authentication via Firebase (Email & Password) 🔐
- ✅ Persistent Data Storage & Schema Modeling in MongoDB Atlas 🗄️
- ✅ Immersive Deep Charcoal Dark Mode UI with Cyan/Blue Gradients 🎨
- ✅ Public Interaction Features (Real-Time Blog Like Counters) 👍
- ✅ Modern Form Input Validation & Protected Routing 🛡️
- ✅ Decoupled Microservice Deployment (Vercel + Render) 🚀
- ✅ Fully Responsive Grid Layout across Desktop, Tablet, and Mobile 📱

---

## 🛠️ Technologies Used

- ⚛️ React.js (JSX, Components, Hooks, React Router DOM, Axios)
- 🟢 Node.js & Express.js (REST API Server)
- 🍃 MongoDB & Mongoose (Cloud Database)
- 🔥 Firebase (Secure User Identity & Authentication)
- 🎨 Tailwind CSS (Utility-First Styling & Custom Glassmorphism)
- ☁️ Vercel (Frontend Hosting) & Render (Backend Hosting)

---

## 🎯 Purpose of the Project

The main objective of this project is to practice and improve my full-stack web development skills by creating a functional, real-world portfolio and CMS application. Through this project, I gained hands-on experience in:

- Architecting secure authentication flows using Firebase alongside a custom Express backend
- Building a decoupled RESTful API and securely connecting it to a React frontend in a production environment
- Designing highly aesthetic, modern UI components using Tailwind CSS utility classes and custom background patterns
- Implementing route protection and admin-only conditional rendering for secure database modifications
- Deploying full-stack applications across independent cloud platforms and managing live CORS policies
